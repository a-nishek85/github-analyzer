# 🚀 GitHub Analyzer

A full-stack web application that analyzes GitHub user profiles and provides insights like repositories, stars, and programming languages.

---

## 🔥 Features

- 🔍 Search any GitHub user
- 📊 View repositories and total stars
- 🧠 Developer score calculation
- 🌐 Language insights (top language, distribution)
- 💾 Save users to database
- 📈 Data visualization using charts

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB
